# RISC-V 内核学习项目
这是一个用于学习 RISC-V 64 位架构内核开发的教学项目，实现了操作系统的核心概念，包括内存管理、进程调度、中断处理和同步原语。 main.c:14-33

# 项目特性
1. 内存管理: 实现物理页面分配器和 Sv39 三级页表虚拟内存系统 Makefile:23-27
2. 进程管理: 支持多任务协作调度，包含上下文切换机制 proc.h:25-31
3. 中断处理: 实现定时器中断和陷阱分发机制 time_interupt.c:15-19
4. 同步原语: 提供自旋锁用于多核环境下的互斥访问 Makefile:47-48
5. UART 驱动: 提供串口输出用于调试和诊断 main.c:25
# 构建要求
1. RISC-V 交叉编译工具链: riscv64-unknown-elf-gcc
2. QEMU 系统模拟器: qemu-system-riscv64
# 构建和运行
```
# 编译内核  
make  
  
# 在 QEMU 中运行  
make qemu  
  
# 清理构建文件  
make clean
```
构建过程使用指定的编译器标志确保与 RISC-V 64 位监管者模式兼容 Makefile:5 ，最终生成 kernel.elf 二进制文件 Makefile:11-12 。

# 系统架构
内核采用单体式设计，所有主要子系统位于单一的监管者模式二进制文件中。系统启动后会在 task_a 和 task_b 之间进行轮转调度 main.c:27-31 。

链接脚本将内核入口点设置在物理地址 0x80000000，这是 QEMU virt 机器中 RAM 的基地址 linker.ld:3 。
